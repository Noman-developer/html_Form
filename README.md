# User Registration Form

A simple registration form made with HTML, CSS and JavaScript. I made it while learning forms.

## What it is

This is a basic user registration page. It asks for a name, email, password, gender, country and a short message. You must also tick the Terms and Conditions box before you can submit.

The form checks everything in the browser:
- Name cannot be empty
- Email must look like a real email address (for example name@example.com)
- Password must be at least 6 characters long
- You must pick Male or Female
- You must choose a country
- You must accept the Terms and Conditions

If something is wrong, a red message appears under that field. If everything is correct, a green success box shows up with a summary of what you entered.

## Tech stack

- HTML
- CSS (style.css)
- JavaScript (script.js) for the validation and the success message

No frameworks and no backend. The data never leaves the browser.

## How to view

Just open `form.html` in any web browser. No setup needed.
